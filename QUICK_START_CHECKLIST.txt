□ STEP 1: RESTORE FILES
  1. Open Recycle Bin (desktop icon)
  2. Press Ctrl + A
  3. Right-click → Restore
  4. Check C:\DigitalBankingSystem has files

□ STEP 2: RUN SCRIPT
  1. Go to C:\DigitalBankingSystem
  2. Double-click: commit-to-github.bat
  3. Wait for "SUCCESS!" message
  4. Press any key to close

□ STEP 3: CREATE GITHUB REPO
  1. Go to: https://github.com/new
  2. Name: DigitalBankingSystem
  3. Select: ⚫ Private (IMPORTANT!)
  4. Uncheck ALL boxes (README, .gitignore, license)
  5. Click "Create repository"

□ STEP 4: GET YOUR TOKEN
  1. Go to: https://github.com/settings/tokens
  2. Click "Generate new token (classic)"
  3. Note: DigitalBankingSystem Access
  4. Check: ✓ repo
  5. Click "Generate token"
  6. COPY and SAVE the token (starts with ghp_)

□ STEP 5: PUSH TO GITHUB
  Open PowerShell and run:
  
  cd C:\DigitalBankingSystem
  
  git remote add origin https://github.com/YOUR_USERNAME/DigitalBankingSystem.git
  
  git branch -M main
  
  git push -u origin main
  
  Username: (your GitHub username)
  Password: (paste your token)

□ STEP 6: VERIFY
  Go to: https://github.com/YOUR_USERNAME/DigitalBankingSystem
  You should see your files!

═══════════════════════════════════════════════════════════════

REPLACE "YOUR_USERNAME" WITH YOUR ACTUAL GITHUB USERNAME!

Example: If username is "johnsmith":
git remote add origin https://github.com/johnsmith/DigitalBankingSystem.git

• Use TOKEN as password, NOT your GitHub password
• Keep repository PRIVATE

• Never commit .env file (it's already excluded)
